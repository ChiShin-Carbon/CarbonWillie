# How to Start

```shell
cd template
```

```shell
npm install
```

```shell
cd fastapi
```

```shell
pip install -r requirements.txt
```

```shell
uvicorn main:app --reload
```

這邊再開一個terminal

```shell
cd template
```

```shell
npm start
```
